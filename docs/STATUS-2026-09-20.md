## Kalshi facts learned today (for open item #1, the Kalshi client)

Public, keyless, worked from this PC:

- `GET https://api.elections.kalshi.com/trade-api/v2/markets?series_ticker=KXNFLGAME&status=open`
  lists game markets. Ticker shape: `KXNFLGAME-26SEP21NYGLAR-LAR` (date, away+home, side).
- The list endpoint returned `null` for `yes_bid`/`yes_ask`. The single-market endpoint
  `GET /markets/{ticker}` carries the prices as strings in `yes_bid_dollars`,
  `yes_ask_dollars`, `no_bid_dollars`, `no_ask_dollars`, `last_price_dollars`, sizes in
  `*_size_fp`, volume in `volume_fp` / `volume_24h_fp`.
- `GET /markets/{ticker}/orderbook?depth=5` returns `orderbook_fp.yes_dollars` and
  `no_dollars` as `[price, size]` string pairs, bids only (the no-side bids are the
  yes-side asks mirrored).
- `close_time` is not kickoff: it was 2026-09-24 for a 2026-09-22 game.
